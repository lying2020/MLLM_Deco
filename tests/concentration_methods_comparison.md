# 注意力热力图聚集度计算方法对比

## 一、方法概述

### 当前方法 (`calculate_concentration_index`)
**核心思路**：基于卷积+聚类+权重筛选的自定义方法

**流程**：
1. 去除最高10个异常点
2. 4×4全1核卷积 → 20×20
3. 选取Top-K个参考点（默认6个）
4. 映射回24×24，收集候选点（参考点+8邻域）
5. 基于距离方差找聚类中心
6. 权重距离筛选，剔除最远10%
7. 计算空间紧凑度（密度×距离因子×分散因子）
8. 计算像素权重比（候选点像素和/总像素和）
9. 综合指标 = (空间紧凑度 + 像素权重比) / 2

### 建议方法（经典统计学指标）
**核心思路**：基于Gini系数、Moran's I、峰值聚集度的统计学方法

**流程**：
1. 高斯平滑预处理
2. 计算基尼系数（值分布不平等性）
3. 计算空间自相关（Moran's I）
4. 计算峰值聚集度（连通区域分析）
5. 综合指标 = w1*Gini + w2*Spatial_Entropy + w3*Peak_Ratio

### 增强方法 (`calculate_concentration_index_enhanced`)
**核心思路**：结合两种方法的优点

**流程**：
1. 去除最高10个异常点（保留当前方法的优势）
2. **高斯平滑预处理**（替代全1核卷积，更符合信号处理理论）
3. **基尼系数**（衡量值分布不平等性，统计学基础扎实）
4. **空间紧凑度**（基于连通区域分析，考虑区域数量和分布）
5. **峰值聚集度**（最大连通区域占比，衡量高注意力区域的集中程度）
6. 综合指标 = 0.4*Gini + 0.3*Spatial_Compactness + 0.3*Peak_Concentration

## 三、各指标含义

### 1. 基尼系数 (Gini Coefficient)
- **范围**：[0, 1]
- **含义**：衡量注意力值分布的不平等性
- **解释**：
  - 0：完全平等（所有像素值相同）
  - 1：完全不平等（所有注意力集中在一个点）
  - **对于注意力热力图**：值越大，表示注意力越集中

### 2. 空间紧凑度 (Spatial Compactness)
- **范围**：[0, 1]
- **含义**：高注意力区域的空间分布紧凑程度
- **计算**：
  - 连通区域数量因子：区域越少，因子越大
  - 最大区域占比：最大连通区域占高注意力区域的比例
  - 综合 = 区域数量因子 × 最大区域占比

### 3. 峰值聚集度 (Peak Concentration)
- **范围**：[0, 1]
- **含义**：高注意力区域是否集中在一个连通块中
- **计算**：最大连通区域面积 / 总高注意力区域面积
- **解释**：
  - 1：所有高注意力像素都在一个连通块中（最集中）
  - 接近0：高注意力像素分散在多个小区域中

### 4. 高注意力区域比例 (High Attention Ratio)
- **范围**：[0, 1]
- **含义**：高注意力像素占总像素的比例
- **阈值**：使用90百分位数作为阈值

## 六、关键区别总结

### 当前方法的特点：
1. ✅ **局部结构敏感**：通过邻域和聚类捕捉局部聚集模式
2. ⚠️ **参数较多**：top_k、阈值等需要调优
3. ⚠️ **计算复杂**：多步迭代，计算成本较高
4. ⚠️ **理论基础较弱**：自定义启发式，缺乏统计学支撑

### 增强方法的特点：
1. ✅ **统计学基础扎实**：基尼系数、连通区域分析都是经典方法
2. ✅ **可解释性强**：每个指标都有明确的统计学含义
3. ✅ **计算稳定**：不依赖复杂的迭代过程
4. ✅ **参数少**：主要参数是权重（w1, w2, w3），可根据需求调整
5. ✅ **鲁棒性好**：对异常值不敏感（已预处理去除最高10个点）

### 建议：
- **论文写作**：优先使用增强方法，指标含义清晰，便于解释
- **深入分析**：可以同时使用两种方法，从不同角度理解注意力分布
- **参数调优**：增强方法的权重可以根据实际数据分布进行调整
